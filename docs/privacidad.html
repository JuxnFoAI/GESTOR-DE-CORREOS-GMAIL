Política de privacidad

Gestor de correos Gmail. Última actualización: 29 de septiembre de 2026.

Quién trata tus datos

No existe ningún servidor ni servicio central. Cada persona instala su propia copia del programa en su cuenta de GitHub y la conecta a su propia cuenta de Google, así que quien ejecuta el programa y decide sobre sus datos eres tú. El autor del código no recibe, no almacena y no puede ver el correo de nadie.

Qué datos de Gmail se usan

De cada correo recibido en la ventana de tiempo que se revisa, el programa pide a la API:

  • el identificador del mensaje;
  • la cabecera From, para saber quién lo envía;
  • la cabecera Subject, para nombrarlo en el resumen;
  • la fecha de recepción, para ordenar el resumen.

La petición se hace pidiendo solo esas cabeceras. El cuerpo del mensaje no se descarga nunca, y tampoco los adjuntos, los contactos, el calendario ni ningún otro dato de la cuenta. También se consulta la dirección de la cuenta conectada, con un único fin: enviarte el resumen a ti y no a una dirección escrita en el código.

Para qué se usan

  • Comparar el remitente con las dos listas que tú escribes en el archivo de configuración.
  • Mover a la papelera de Gmail los correos de la lista de remitentes no deseados.
  • Enviarte a tu propia cuenta un resumen de lo que se movió y de lo que conviene revisar.

No se usan para nada más. No hay perfilado, ni publicidad, ni analítica, ni entrenamiento de modelos de inteligencia artificial.

Dónde se procesan y cuánto se conservan

El programa se ejecuta en GitHub Actions durante unos segundos, cada seis horas. Los datos de tus correos existen solo en la memoria de ese proceso y desaparecen cuando termina. No hay base de datos, ni archivos, ni copias, ni caché. Lo único que queda es el correo de resumen, y queda en tu propio buzón.

El registro de ejecución de GitHub Actions guarda cuántos correos se revisaron y el asunto de la ficha de resumen, nunca credenciales ni el contenido de los mensajes.

Con quién se comparten

Con nadie. El programa no tiene dependencias en tiempo de ejecución y las únicas direcciones de red a las que se conecta son las de Google: el servicio de tokens de OAuth y la API de Gmail.

Uso limitado

El uso que esta aplicación hace de la información recibida de las API de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Permiso que se solicita

Un único permiso: https://www.googleapis.com/auth/gmail.modify. Es el mínimo que permite mover un correo a la papelera y enviar el resumen. No permite borrar correos de forma permanente, así que lo que el programa mueve se puede recuperar desde la papelera de Gmail durante unos treinta días.

Cómo retirar el acceso

En cualquier momento, desde los permisos de tu cuenta de Google, puedes quitarle el acceso. El programa deja de funcionar en la siguiente ejecución. Para cerrarlo del todo, borra también las credenciales guardadas en los secrets de tu repositorio y desactiva la ejecución programada.

Seguridad

Las credenciales viven en los secrets del repositorio, cifrados, y nunca en el código. El permiso se concede con PKCE y verificación de state. Los mensajes de error incluyen el código HTTP pero nunca la respuesta de Google, para que un registro no acabe mostrando una credencial.

Cambios

Si esta política cambia, la fecha de arriba cambia con ella y el cambio queda registrado en el historial del repositorio.

Contacto
